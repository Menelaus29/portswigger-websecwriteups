Server-Side Template Injection
Congratulations. SSTI solved.

The uploaded filename is passed raw into Flask's render_template_string(). Jinja2 evaluates {{ }} expressions inside the string, including arbitrary Python code reachable through the object graph.

▶ Vulnerable call: render_template_string("... filename ...")
